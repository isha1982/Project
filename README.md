# 🏠 Real Estate Price Prediction using Machine Learning

This project focuses on predicting real estate housing prices using historical data and Machine Learning techniques.

## 🚀 Overview
Built a regression-based machine learning model to estimate housing prices accurately. The project involves data preprocessing, model training, evaluation, and comparison of multiple algorithms.

## 🧠 Algorithms Used
- Linear Regression  
- Decision Tree Regressor  
- Random Forest Regressor  

## 📊 Results
Random Forest Regressor performed the best with an R² score of **0.87**, providing the highest prediction accuracy.

## 🛠️ Technologies Used
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Matplotlib  

## 📈 Features
- Data Cleaning & Preprocessing  
- Model Training & Evaluation  
- Performance Comparison of Algorithms  
- Visualization of Results  

## 📂 Project Structure
- `Dragon_Real_Estate.ipynb` → Main notebook with implementation  
- `README.md` → Project documentation  

## 🎯 Conclusion
This project demonstrates how machine learning models can be effectively used for price prediction and highlights the importance of model selection for better accuracy.
